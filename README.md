# Livecheck

**Your AI built the site. We get it actually live.**

Convex All Gas Hackathon entry — sponsored by OpenAI, Firecrawl, and AgentMail.

## The problem

Someone with no technical background builds a website with AI. The code is clean, the copy is
decent, the layout looks professional. Then they try to launch it. The contact form submits into
nothing. The mobile view collapses. DNS "reads like a foreign language." SSL fails and every
visitor gets a scary browser warning.

The site sits 80% done. The last mile kills the launch.

## Who it's for

A business owner, not a developer. A barber, a contractor, a bookkeeper, a personal trainer.
Every output is plain English — no Lighthouse score dumps, no jargon.

## Stack

- **Convex** — backend, scheduled re-checks, real-time results
- **Firecrawl** — crawls the live site to find what's actually broken
- **OpenAI** — turns technical findings into plain-language fixes
- **AgentMail** — sends the report and receives replies
